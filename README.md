# Motorola Mobile Sales Analysis Dashboard

## Project Overview
This project presents an interactive Power BI dashboard that analyzes Motorola mobile sales data. It provides insights into sales performance, top-selling products, regional sales distribution, and customer behavior.

## Key Insights
- Total Sales, Quantity Sold, and Transaction Overview
- Top-Selling Mobile Models
- City-wise Sales Distribution
- Monthly Sales Trends
- Customer Rating Analysis
- Payment Method Distribution

## Tools & Technologies
- Power BI
- Data Visualization
- Data Analysis

## Objective
The goal of this project is to transform raw sales data into meaningful insights and demonstrate my ability to build interactive dashboards for business decision-making.
